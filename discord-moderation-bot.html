What it actually does

Most "best free Discord moderation bot" lists are written by the bots themselves. So here is the plain version. Apricus is a general-purpose Discord bot whose moderation toolset is command-driven: a moderator runs the action, the bot enforces it and keeps a written record. It does not include an AI keyword auto-mod that silently bans people, and we are not going to claim that it does. What you get is fast, auditable moderation plus the join/leave and engagement systems that surround it.

Moderation, autorole, welcome, starboard & leveling

Core moderation commands

Take action without leaving Discord: /ban, /kick, /mute, /unmute. Permissions are respected, so only staff with the right roles can run them. /addbot - get a clean link to add Apricus to another server.

Warnings with history

/warn records a reason against a member, /warnings shows that member's full record, and /clearwarnings wipes it when the matter is settled. Progressive discipline you can point to later.

Cleanup & announcements

/purge clears spam or a runaway channel in one command, /broadcast posts one announcement to the channels you choose, and /serverinfo gives staff a quick read on the server.

Autorole on join

/autorolesetup and /autorole set assign roles the moment someone joins — starter roles, pronoun roles, access roles. /autorole view and /autorole remove manage the list.

Welcome & goodbye messages

/welcome set posts a greeting in the channel you pick, /welcome test previews it before you commit, and /goodbye set handles the leave message. /onboard covers the first-minute journey.

Starboard for good posts

/starboard set mirrors messages that reach a reaction threshold into a highlights channel. Tune it with /starboard threshold, /starboard remove and /starboard view.

XP leveling & rankings

Activity earns XP: /rank and /leaderboard show where people stand, /levelup announces milestones, and /xpstats plus /addxp let staff audit or adjust a member's XP.

Setup without a spreadsheet

/quicksetup and /setup walk through the basics, /config holds the settings, and /help lists what is available from inside Discord. No dashboard login required.

Things that work the second you add it

Not everything needs configuring. /tour gives you an interactive tour, /dailytrivia posts a trivia game you can run in any channel, /daily hands out one daily reward, /poll runs a poll in the current channel, and /feedback lets members file suggestions without a moderator relaying them.

Why server owners pick a free moderation bot like this

A moderation bot earns its place by being nearby. If issuing a warning means opening a website, logging in and finding the right server ID, staff will simply skip it and the record fills with holes. Because Apricus answers to slash commands, /warn takes about four seconds from a phone, so the history stays complete.

The second reason is that moderation rarely lives alone. Autorole means new members get read access before they message your mods. Welcome and goodbye messages mean joins are visible in a staff channel instead of invisible. Starboard and leveling give people a reason to behave well, which is the cheapest moderation there is. Running four separate bots for those four jobs is how you end up with four permission grants and four sets of settings to forget.

Is there a Discord moderation bot that is free?

Yes — Apricus is free to add and the moderation, autorole, welcome, starboard and leveling commands described on this page are available without a subscription or a "premium gate". There is no trial timer and no command that works for seven days and then disappears. What you see in /help is what you get.

Does Apricus work as an auto mod for Discord?

Partly, and only in the sense that it automates the parts a bot can do reliably. Autorole and welcome/goodbye messages run automatically on every join and leave, and /purge makes cleanup instant. It does not include a keyword or AI auto-mod that detects bad messages and bans people on its own. If you need silent automated enforcement, you should also enable Discord's built-in content filter — pretending otherwise would be a bad reason to pick the wrong bot.

How do I set up a moderation bot in Discord?

Add it with the button on this page, then give it a role above the roles it must manage and the required permissions in the invite. In your server run /quicksetup or /setup, then /autorole set for join roles, /welcome set and /goodbye set for join/leave messages, and /starboard set if you want a highlights channel. Test with /welcome test before you rely on it.

Can I earn Apricots for adding Apricus to a new server?

Yes. /installref gives you a personal install link and /installboard shows the referral leaderboard, so you earn Apricots when Apricus lands in a NEW server through your link. Servers that already have Apricus do not count a second time.
