How it works

Three steps. Half a minute.

No config files, no dashboards, no channel-by-channel clicking. Apricus bootstraps your server for you.

Invite Apricus

Hit Add to Discord, pick your server, approve the permissions. Apricus is online before the invite window closes.

Run /config

One click creates your welcome, rules, general, bot-commands, starboard, suggestions, logs and mod-log channels — plus roles, permissions and sensible defaults for every module.

Run /tour

A guided, interactive tour walks you through leveling, economy, moderation, polls and rewards with live buttons. Learn the bot while it learns your server.

FAQ

Questions, answered

Straight answers about privacy, price and how to get Apricus in and out of your server.

Does Apricus store my messages?

No message content is ever stored. Apricus reads a message only in the moment it needs to — for example to count XP, to check a starboard threshold, or to run a moderation action — and then discards it. What persists is metadata only: member and channel IDs, XP totals, coin balances, warning case records and configuration settings. All of it is deleted when the member leaves (after a short grace period) or when you run the data-removal command.

Is Apricus free? Is there a premium tier?

Apricus is completely free, with no premium paywall. There is no “pro” tier, no locked modules, no vote-to-unlock gates and no command limits. Every feature on this page is available to every server on day one.

How do I set it up?

Three steps: 1) click Add to Discord and approve the invite on your server. 2) Run /config — Apricus previews the channels, roles and permissions it will create, then applies them in one go (usually under 15 seconds). 3) Run /tour for a guided walkthrough of leveling, economy, moderation, polls and rewards. Existing servers are fine too: /config detects what you already have and only fills the gaps.

How do I remove Apricus?

Treat it like any other member: Server Settings → Roles & Members → Apricus → Remove member (or kick it with moderation tools). No uninstall step, no leftover hooks. Apricus immediately stops processing events for your server, and you can run /config remove first if you want Apricus to delete the channels and roles it created before it leaves. Server data is purged from our storage within 30 days of removal.

Which permissions does the invite need, and can I trim it?

The invite link requests only the granular permissions Apricus actually needs (Manage Roles, Manage Channels, Manage Messages, Moderate Members, Add Reactions, Embed Links) — Administrator is not required. Run /addbot any time for a fresh link, and if a command is ever missing something Apricus tells you exactly which permission to add.

How do I get rewarded for adding Apricus to another server?

Run /installref to get your personal install link, then add Apricus to a server you do not already have it in. Apricus credits 250 points to you as soon as it lands in that NEW server — re-adding it to a server it is already in does not count. Track your standing on the /installboard leaderboard.
